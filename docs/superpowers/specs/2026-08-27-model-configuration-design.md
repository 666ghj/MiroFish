# 模型配置中心设计

## 目标

为 MiroFish-local 增加页面化模型配置中心。用户只需配置三种模型，后台按运行阶段自动选择模型：

1. Embedding 模型：负责向量写入和语义检索。
2. 高能力线上模型：负责少量、高杠杆、质量优先的规划和最终产出。
3. 高吞吐本地模型：负责大量、重复、延迟与成本敏感的抽取和模拟行为。

本功能使用全局默认配置，并在项目首次调用模型前保存不可变配置快照。修改全局配置只影响新任务，不影响已开始项目和运行中任务。

## 阶段路由

### 高能力线上模型

- 文档本体设计。
- Agent 人设生成。
- 全局模拟参数与事件规划。
- 报告检索规划和采访策略。
- 报告章节、最终总结与报告后问答。

### 高吞吐本地模型

- Graphiti 实体和关系抽取。
- Graphiti 实体去重、摘要与关系更新。
- Twitter/Reddit 正式模拟中的 Agent 行为决策。
- 模拟记忆抽取与图谱回写。

### Embedding 模型

- 图谱节点、关系和文本向量写入。
- 报告、采访、问答和图谱工具产生的语义查询。

Agent 人设使用高能力模型，因为人设决定后续立场、行为一致性和模拟可信度。通过批量生成、严格 Schema 校验、失败批次单独重试和即时持久化控制成本。

## Provider 连接

模型角色不直接重复保存 Provider 凭据，而是引用可复用连接。支持：

- ChatGPT OAuth / Codex Gateway。
- OpenAI-compatible 在线 API。
- OpenAI-compatible 本地文本模型。
- OpenAI-compatible Embedding 服务。

连接字段：

- `connection_id`、名称和 Provider 类型。
- Base URL。
- API Key 密文，或“凭据由外部 OAuth Gateway 管理”标记。
- 是否本地服务。
- 是否启用。
- 创建时间和更新时间。

连接支持新增、编辑、测试、禁用和删除。仍被模型角色或配置版本引用的连接禁止删除，并返回明确依赖信息。

## 三个模型角色

### Embedding

- Provider 连接。
- 模型名称。
- 向量维度。
- 最大批次。
- 超时。

### 高能力线上模型

- Provider 连接。
- 模型名称。
- 温度。
- 最大输出 Token。
- 超时。
- 并发限制。

### 高吞吐本地模型

- 本地 Provider 连接。
- 模型名称。
- 温度。
- 最大输出 Token。
- 超时。
- 最大并发。
- 失败时是否回退高能力模型。
- 连续失败阈值。

## 页面

顶部导航增加“模型配置”，路由为 `/settings/models`。

### 状态概览

三张角色卡片显示：

- 当前连接和模型。
- 在线或离线状态。
- 最近测试时间。
- 并发限制。
- 使用该模型的运行阶段。
- 配置错误或回退提示。

### 职责配置

三个角色分别选择连接和模型。高级参数默认折叠。Embedding 提供“测试向量”，文本模型提供“测试文本”和“测试结构化输出”，高吞吐模型额外提供“测试吞吐”。

更换 Embedding 模型或向量维度时必须显示不兼容警告。已有图谱不允许静默切换向量空间；用户必须新建图谱或明确执行重建流程。

### Provider 管理

列表显示连接类型、Base URL、脱敏凭据状态、启用状态和最近测试。API Key 只允许写入，空值表示保留旧 Key，页面永远不能读取完整 Key。

### 应用流程

1. 用户编辑草稿。
2. 页面显示发生变化的角色。
3. 对变化连接执行对应测试。
4. 未通过或测试已过期的配置禁止应用。
5. 点击“应用配置”创建不可变版本并原子切换当前版本。
6. 新任务使用新版本，已有项目继续使用快照。

移动端三张角色卡片纵向排列。所有操作提供加载、成功、失败、空状态和键盘焦点，不只依赖颜色表达状态。

## 数据模型

配置与已有任务历史共用 SQLite 文件体系，但使用独立表：

### `model_connections`

- 连接基础信息。
- 加密后的 API Key。
- OAuth 外部管理标记。
- 启用状态。

### `model_role_drafts`

- 当前尚未应用的三个角色草稿。
- 引用连接和模型参数。

### `model_config_versions`

- 每次应用生成不可变版本。
- 保存三个角色的完整非敏感配置和连接引用。
- 记录创建时间和来源版本。

### `model_config_state`

- 当前生效版本。
- 是否完成首次环境变量导入。

### `project_model_snapshots`

- 项目 ID。
- 配置版本 ID。
- 三个角色的不可变配置快照。
- 创建时间。

### `model_test_runs`

- 连接、模型角色和测试类型。
- 耗时、状态、安全错误代码和测试时间。
- 不保存提示词、模型输出或凭据。

任务 metadata 增加配置版本、模型角色、实际 Provider、实际模型和是否回退。日志同样只记录这些安全字段。

## 凭据安全

API Key 使用应用主密钥加密后存入 SQLite。主密钥保存于：

```text
<UPLOAD_FOLDER>/model-config/master.key
```

- 目录权限 `0700`。
- 文件权限 `0600`。
- SQLite 不保存明文 Key。
- API 只返回脱敏提示，例如 `sk-***abcd`。
- 日志、任务 metadata、测试记录和错误响应不得包含 Key。

该机制防止数据库文件单独泄露后直接暴露凭据，不承诺抵御完整主机控制。

ChatGPT OAuth Token 继续由 `codex-gateway` 或 `direct-oauth-gateway` 管理。MiroFish 只保存内部 Gateway 地址、内部认证凭据和脱敏账户状态，不读取 OAuth access token 或 refresh token。

## 运行时架构

新增统一 `ModelRouter`。业务代码不再直接决定模型，改为按角色获取客户端：

```python
router.get_text_client(ModelRole.HIGH_CAPABILITY, project_id=project_id)
router.get_text_client(ModelRole.HIGH_THROUGHPUT, project_id=project_id)
router.get_embedder(project_id=project_id)
```

路由器优先读取项目快照；没有项目快照时读取当前生效版本；尚未应用页面配置时回退现有环境变量。

项目在第一次模型调用前原子创建快照。多个线程同时开始时只能生成一份快照。

正式模拟运行于独立子进程。启动时由后端把项目快照转换为该进程专用环境变量：

- 高吞吐连接的 Key、Base URL、模型与参数。
- 不把高能力或 Embedding 凭据传给不需要它们的模拟子进程。

## 回退规则

高吞吐模型仅在显式开启回退且发生以下错误时回退到高能力模型：

- 连接超时或不可达。
- 连续返回非法 JSON。
- 不支持要求的结构化输出。
- 达到配置的连续失败阈值。

禁止自动回退：

- Embedding 失败或维度不符。
- 高能力模型失败。
- API Key 或 OAuth 失效。
- 配额不足。
- 用户关闭回退。

回退次数有限且不得形成循环。每次回退写入任务历史和安全日志，页面显示黄色状态提示。

## API

新增 `/api/settings/models` Blueprint，包含：

- 连接列表、创建、更新、禁用和删除。
- 连接文本、结构化输出、吞吐和 Embedding 测试。
- 三角色草稿读取和保存。
- 草稿校验与应用。
- 当前生效版本和版本历史。
- 项目配置快照读取。

所有写接口校验 URL scheme、模型名称、数值范围、连接类型与角色兼容性。API 错误只返回安全错误码和可操作说明。

## 迁移与兼容

首次进入模型配置时，从环境变量生成默认连接和角色草稿：

- `LLM_*` → 高能力模型。
- `GRAPHITI_LLM_*` → 高吞吐模型。
- `GRAPHITI_EMBEDDING_*` → Embedding。
- `LLM_BOOST_*` 记录为兼容连接，但不作为核心角色。

导入只执行一次，不修改 `.env`。页面尚未应用配置时，所有业务继续使用当前环境变量，升级后不能立即中断现有流程。

已有项目第一次继续调用模型时保存当时有效配置快照。新项目在第一次调用模型前保存快照。

## 测试

后端覆盖：

- 连接和角色草稿的增删改查。
- API Key 加密、脱敏、权限和日志扫描。
- 连接依赖删除保护。
- 文本、结构化、吞吐和 Embedding 测试契约。
- 配置应用、不可变版本和原子当前版本切换。
- 项目快照并发一致性。
- 环境变量首次迁移与兼容回退。
- 所有业务阶段映射到正确角色。
- 高吞吐模型有限回退。
- Embedding 与高能力模型禁止自动降级。
- 正式模拟子进程只收到所需快照凭据。
- 运行中任务不受全局配置更新影响。

前端覆盖：

- 三角色状态卡片。
- Provider 连接管理。
- 草稿、测试、应用和版本状态。
- 未测试配置禁止应用。
- API Key 不可回读。
- 删除依赖连接时阻止。
- Embedding 兼容性警告。
- 桌面端和移动端布局。
- 浏览器无控制台错误和错误覆盖层。

## 不在首版范围

- 自动下载或启动本地模型服务。
- 自动重建不兼容的历史向量图谱。
- 多租户凭据隔离。
- 云端集中式密钥管理服务。
- 根据实时成本自动选择模型。
